Chimimi is a customized e-commerce platform built using the Laravel framework for a local culinary brand specializing in premium risoles. Developed in a team of two, this project digitizes the brand's sales operations, providing a secure and scalable digital storefront to streamline customer orders, manage product assets, and track inventory through a modern web-based system.

## 🛠️ Technical Features & Logic

### ⚙️ Architecture & Data Layer
- MVC Architecture: Implemented the Model-View-Controller (MVC) design pattern using Laravel to ensure a clean separation of concerns, modularity, and code maintainability.
- Eloquent ORM & Relational Databases: Leveraged Laravel's Eloquent ORM for fluid database interactions, optimizing querying logic and managing data relationships between Users, Products, and Orders.

### 🔐 Security & Access Control
- Secure Authentication Engine: Utilized Laravel's native authentication mechanisms and middleware to enforce secure Role-Based Access Control (RBAC) isolating Administrator capabilities from standard Customer interactions.
- Administrative CRUD Suite: Built a comprehensive backend control center for administrators to manage live product listings, handle pricing adjustments, execute secure image uploads, and track inventory updates in real time.

### 🎨 Frontend Integration
- Blade Templating Engine: Developed a dynamic, server-rendered frontend using Blade templates to maintain modular UI components and deliver a smooth user experience across the product catalog and checkout flows.
